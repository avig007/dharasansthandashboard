# Dhara Sansthan – RO Water ATMs Dashboard

Interactive dashboard of the Community RO Water ATM network run by Dhara Sansthan (supported by Bosch India Foundation) around Jaipur, April–September 2026.

Built by Avijeet Gupta (SPJIMR PGPBM, DoCC project) from Dhara Sansthan's plant spreadsheet.

Live site: https://avig007.github.io/dharasansthandashboard/

The whole dashboard is one self-contained file, `index.html`.
